# mall 接口自动化测试 - 依赖清单
#
# 安装方式：
#   .venv\Scripts\python.exe -m pip install -r requirements.txt
#
# 版本已固定（==），保证换台机器/换个人跑出来的结果一致。
# 如果写成 >= 或不写版本，某天自动装到不兼容的新版本，测试莫名其妙失败，
# 排查半天才发现是依赖升级导致的 —— 这是很常见的坑。

# HTTP 客户端。选 requests 而不是 urllib：
# 它的 API 更直观，而且 Session 对象自带连接池，批量请求时性能明显更好。
requests==2.34.2

# 测试框架。pytest 相比 unittest 的优势：
#   - 用原生 assert，不用记 assertEqual/assertTrue 那一堆方法
#   - fixture 机制比 setUp/tearDown 灵活得多（支持不同 scope）
#   - 参数化（parametrize）让数据驱动变得非常简单
#   - 插件生态丰富（本项目的 HTML 报告就靠插件）
pytest==9.1.1

# HTML 测试报告插件。生成自带 CSS/JS 的单文件报告，
# 可以直接发给别人看，不需要额外部署服务。
pytest-html==4.2.0

# YAML 解析。用来存放测试数据，实现"数据与代码分离"。
PyYAML==6.0.3

# ---------------------------------------------------------------
# 可选依赖（按需安装，本框架核心不依赖它们）
# ---------------------------------------------------------------

# pytest-rerunfailures  失败自动重试，用于规避偶发的环境抖动
# allure-pytest   生成 Allure 报告（需要额外装 Java 环境和 Allure 命令行）
# jsonschema      做响应体的 JSON Schema 校验，比逐字段断言更严谨
